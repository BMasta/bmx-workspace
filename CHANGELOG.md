# Changelog

## Version 0.1.2

### Changed
- Fixed parsing issue when checker wouldn't correctly recognize line splices in preprocessor directives

## Version 0.1.1

### Changed
- Fixed parsing issue when checker would ignore ranges after finding a line comment anywhere in the file

## Version 0.1.0

### Added
- In-text highlighting of problematic line breaks
- Configurable desired line break indentation
- Configurable tab size for line break indentation calculations
- Command "bmx-workspace.fixLineBreaks" that automatically fixes problematic line breaks
- Settings to enable/disable each highlighting type.

## Version 0.0.2

### Changed
- Fixed preprocessor directive handling

## Version 0.0.1

### Added
- Line break indentation checking for C files
